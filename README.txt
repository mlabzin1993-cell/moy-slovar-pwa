МОЙ ЧЕТЫРЁХЪЯЗЫЧНЫЙ СЛОВАРЬ — PWA 0.4
========================================

СОДЕРЖИМОЕ АРХИВА
- index.html — приложение, основанное на проверенной версии 0.3
- manifest.webmanifest — описание устанавливаемого приложения
- service-worker.js — кэширование файлов и офлайн-запуск
- icons/icon-192.png и icons/icon-512.png — иконки приложения

ЧТО СОХРАНЕНО
- Все 124 встроенные записи словаря из переданного HTML.
- Поиск по четырём языкам и примечаниям.
- Добавление, редактирование и удаление записей.
- Импорт и экспорт JSON.
- Сортировка записей.
- Ключ localStorage: fourLangDictionary_v03.

ПУБЛИКАЦИЯ НА GITHUB PAGES
1. На компьютере войдите в GitHub.
2. Создайте новый репозиторий, например moy-slovar-pwa.
   Для простоты можно сделать его Public.
3. Откройте репозиторий и выберите Add file -> Upload files.
4. Распакуйте этот ZIP на компьютере и загрузите СОДЕРЖИМОЕ папки
   moy_slovar_pwa_v0_4, а не сам ZIP и не внешнюю папку.
   В корне репозитория должны сразу лежать index.html,
   manifest.webmanifest, service-worker.js и папка icons.
5. Нажмите Commit changes.
6. Откройте Settings -> Pages.
7. В разделе Build and deployment выберите:
   Source: Deploy from a branch
   Branch: main
   Folder: /(root)
   Нажмите Save.
8. Подождите завершения публикации. GitHub покажет адрес сайта
   вида https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/
9. Откройте этот адрес в Chrome. Для установки на Android используйте
   меню Chrome -> Установить приложение или Добавить на главный экран.

ВАЖНО О ПЕРЕНОСЕ СЛОВ
У сайта на GitHub Pages будет другой адрес (origin), поэтому браузер
создаст для него отдельное localStorage. Старые пользовательские записи
из локальной версии 0.3 автоматически туда не попадут.

Перед переходом:
1. Откройте старую версию 0.3 там, где сейчас хранится ваш словарь.
2. Нажмите «Экспорт JSON» и сохраните резервную копию.
3. Откройте опубликованную PWA по HTTPS.
4. Нажмите «Импорт JSON» и выберите сохранённый файл.
5. Убедитесь, что количество записей и новые слова на месте.

ОФЛАЙН-РЕЖИМ
После первого успешного открытия опубликованной PWA и установки
Service Worker приложение сможет открываться без сети. Первую загрузку
и регистрацию Service Worker нужно выполнить при подключённом интернете.
Проверять офлайн-режим следует после этого, а не открытием HTML-файла
напрямую с диска.

ОБНОВЛЕНИЯ
При публикации новой версии заменяйте файлы в корне репозитория.
Не меняйте ключ localStorage fourLangDictionary_v03 без отдельной
миграции данных. После обновления может понадобиться закрыть и заново
открыть приложение; при необходимости очистить кэш сайта можно будет
отдельно, но не очищайте данные сайта, если хотите сохранить слова.
